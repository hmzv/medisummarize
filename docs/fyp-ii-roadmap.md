# FYP-II roadmap

- LoRA or other parameter-efficient adaptation
- Reranking and expanded retrieval experiments
- Biomedical embedding comparison after stating model size and license
- FAISS (or another ANN library) as a drop-in for the current exact cosine index
- Durable background jobs
- Production encryption and key management
- Comprehensive audit logging
- Multi-role clinical workflows
- Hospital / EHR integration
- Large-scale clinical validation with qualified reviewers
